## Overview  
This monorepo (or project-hub) contains a variety of past, side-and-archive projects ranging from C++ desktop utilities to full-stack web apps with React/Next.js.  
Each folder is a self-contained project, often used for learning, experimentation, or personal utility.  
While some are maintained, many are in "archive" status — you’re welcome to explore, fork, or revive as you see fit.

## How to Use / Clone  
1. Clone this repository:  
   ```bash  
   git clone https://github.com/RyanLarge13/Projects.git  
   cd Projects  
    ```

2. Browse into any project folder. Each has its own dependencies & instructions (in that project's `README.md`).
3. For archived projects: Be aware that dependencies or environments may be outdated — use at your own discretion.

## Contributing

Since many of these are personal/archive projects, open‐source contributions aren’t the primary goal — however:

* Feel free to fork any project, revive it, adapt it to your needs.
* If you improve a project and want to share it back, submit a Pull Request and include a summary of what you changed.
* Always respect the original license and project intent.
